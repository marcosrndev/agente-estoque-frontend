Como entrar no sistema

Digite seu usuário e senha fornecidos pelo administrador (Marcos) e clique em Entrar.

Cada pessoa tem login próprio — suas cotações e ações ficam registradas com seu nome automaticamente.

Esqueceu a senha? Peça ao administrador Marcos para redefini-la na aba Admin.
Como importar dados do ERP

1. Exporte a aba "Sugestão de compra" do ERP como CSV

2. Clique em Importar CSV no canto superior direito

3. Cole os dados e clique em Importar

4. Os dados vão automaticamente para o servidor — todos os usuários veem imediatamente.

Ao importar: cotações concluídas são apagadas. Cotações em andamento são mantidas com aviso de "dados atualizados".

Faça a importação uma vez por semana, preferencialmente na segunda-feira.

Como montar um pedido

1. Vá na aba Montar Pedido

2. Clique nos chips de grupos para selecionar (pode combinar vários)

3. Escolha a cobertura em meses — de 3 a 12. A quantidade é calculada proporcionalmente

4. Preencha o Preço dos produtos (após o nome) — o Valor Total calcula automaticamente

5. Na coluna Qtd, digite manualmente ou use o botão Auto para preencher com base na cobertura

6. Preencha Fornecedor, Condição de pagamento, etc. no rodapé

7. Clique em Exportar Excel

Os dados de preço e quantidade são salvos automaticamente — você pode continuar de onde parou.
Como usar as Cotações

Marcar: no Montar Pedido, clique no cabeçalho do grupo e em "Marcar cotação". Seu nome aparece automaticamente.

Grupos concatenados: ao marcar, se você tiver vários grupos selecionados, o sistema pergunta se quer marcar todos juntos como uma sessão.

Abrir no Pedido: na aba Cotações, clique em "Abrir no Pedido" para carregar os grupos diretamente com os dados salvos.

Concluir: quando terminar, clique em "Concluir" — fica registrado com data e hora para avaliar produtividade.

⚠️ Se os dados forem atualizados enquanto você cota, um alerta laranja avisa "Dados atualizados".
Urgências e prioridades

Crítico — estoque zerado ou abaixo de 50% do mínimo

Atenção — abaixo do estoque mínimo

OK — estoque adequado

Urgência % = quanto falta para atingir o mínimo. 100% = zerado.

Prioridade dos grupos (#1, #2...): automática por Classe A > B > C > valor de compra.
